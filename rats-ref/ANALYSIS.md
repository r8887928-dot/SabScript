# Разбор референса «1000 бутылок и 10 крыс» (TikTok, 576×1024, 30 к/с, 110,9 с)

## Формат
- Логическая задачка-головоломка. Рассказчик за кадром (мужской, спокойный, чуть таинственный), ~2,4 слова/с, 255 слов за 106,6 с.
- Структура: условие (0–14 с) → вопрос зрителю «Сможете понять, как это сделать?» (14 с) → «есть хитрый приём» → решение по шагам (номер → двоичный код → крысы в ряд → капля где единица → примеры 3 и 347) → ожидание сутки → чтение ответа → «вот почему это работает» (2¹⁰ = 1024) → итог «вы нашли…» (106 с).
- В середине вшита реклама VPN (~58–64 с) — баннер поверх кадра.

## Картинка
- Мир: тёплый 3D-винный погреб / таверна: деревянные стеллажи, арки, фонари, гирлянды-лампочки, каменная брусчатка, цветы в горшках, медные трубы и вентиль-штурвал. Тёплый свет, оранжевые лампы, глубина резкости.
- Персонаж: плоский 2D «боб» — огромная белая голова, монокль на цепочке, синий костюм, красный галстук, ножки-палочки. Хитрые прищуренные выражения, ухмылка с зубами. Держит бутылку с номером.
- Реквизит: ряды зелёных бутылок с белыми этикетками (номер + двоичный код), белые мультяшные крысы, табло с перекидными цифрами (1000 / 0405 / 0347), подсвеченные жёлтые плитки двоичных цифр 0/1, таблички с номерами позиций 10…1 перед крысами.
- Камера: почти каждые 1–2 с новый кадр или плавный проезд; длинные пролёты вдоль рядов бутылок, наезды на табло, крупные планы лица. Склеек почти нет — переходы проездом камеры.

## Текст
- Субтитры по ОДНОМУ слову, по центру в нижней трети, белые заглавные, жирный шрифт с тёмной обводкой.
- Числа и двоичные коды показываются на 3D-табло в мире, а не плашками.

## Звук
- Голос сверху, тихая фоновая музыка, щелчки перекидных цифр, писк крыс.

## Почему держит
- Вопрос в первые 14 с + «сможете понять?» → зритель остаётся ради ответа.
- Пошаговое решение с наглядными примерами, финальное «вот почему это работает».
