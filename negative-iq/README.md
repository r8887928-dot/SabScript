# «Что, если у всех людей на Земле внезапно станет отрицательный IQ?»

Вертикальный (9:16, 1080×1920, 30 к/с) научно-фантастический ролик ~3 минуты: стилизованная 3D-графика
(three.js) + 2D-слой с субтитрами в Remotion. Озвучка — запись автора (`assets/voice/voice.mp3`), всё остальное
(город, персонажи, звуковые эффекты, музыка) сгенерировано кодом — без чужих ассетов и без авторских прав.

Готовое видео: `final/negative_iq_9x16.mp4` (сжатая копия для телефона; полное качество рендерится командой ниже).

## Как устроено
- `tools/plan.py` — главный таймлайн. Читает тайминги слов озвучки (`assets/voice/words_raw.json`, faster-whisper),
  режет голос по паузам, вставляет заставки-главы (факт + «часы эксперимента»), задаёт планы (55 шт.), субтитры,
  ~120 звуковых событий и смену музыкального настроения. Пишет `src/timeline.json` — его читают и картинка, и звук.
- `src/three/` — 3D-библиотека: `city.tsx` (процедурный город: панельки, кирпич, стекло, магазины, фонари, деревья,
  светофоры, «волна» отключения света, зарастание, мусор), `person.tsx` (мультяшные персонажи с позами и эмоциями),
  `vehicles.tsx` (машины, скорые, полиция, самолёты), `earth.tsx` (Земля с ночными огнями), `props.tsx`, `core.tsx`.
- `src/scenes/` — сцены по главам (`Hook`, `Morning`, `Ten`, `Hour`, `Day1`, `Day3`, `Late`, `Final`, `Interlude`).
- `src/overlay/Overlays.tsx` — субтитры с выделением ключевых слов, датчик IQ, титр, карточки фактов, часы
  эксперимента, HUD, переходы (whip / zoom / glitch / flash / fade).
- `tools/audio/` — синтез звука: `sfx.py` (~65 эффектов), `music.py` (12 настроений оригинальной музыки),
  `mix.py` (голос + эффекты + атмосферы + музыка с приглушением под голос, нормализация −14 LUFS).

## Сборка
```bash
npm install
python3 -I tools/plan.py            # таймлайн (нужны ffmpeg и numpy)
python3 tools/audio/mix.py          # саундтрек -> out/audio/mix.wav (numpy, scipy)
npx remotion render src/index.ts NegativeIQ out/render/video.mp4 --concurrency=2 --crf=17
ffmpeg -i out/render/video.mp4 -i out/audio/mix.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k final.mp4
```
`remotion.config.ts` настроен на программный WebGL (`swangle`) — рендер работает и без видеокарты.
Контрольные кадры: `node scripts/stills.mjs all out/stills 0.5 && python3 scripts/sheet.py out/stills sheet.jpg`.

## Факты в ролике
- Средний IQ = 100: шкалы IQ нормируются так, чтобы среднее по популяции было 100 (стандартное отклонение 15).
- Мозг ≈ 2 % массы тела, но потребляет ≈ 20 % энергии организма в покое.
- ≈ 100 000 авиарейсов в день — порядок величины по данным IATA / сервисов отслеживания рейсов.
- > 5 млрд пользователей интернета (ITU, 2023–2024: ~5,4–5,5 млрд, больше половины населения Земли).
- Запасов в магазинах большого города хватает на несколько дней — розница работает «точно в срок».
- Эффект Даннинга — Крюгера (1999): люди с низкой компетентностью склонны переоценивать свои способности.
